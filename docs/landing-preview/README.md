# Sentinel landing-page concept

Open index.html to review the standalone design. It does not execute a scanner, read files, or change the running app.

The design distinguishes bounded checks of common AI locations in the personal prototype from ZIP inspection in the public source. These are separate source versions, and neither establishes comprehensive coverage. Verify actual controls, scope, and outputs against the current app before integration.

Run `python docs/landing-preview/check_static.py` from the repo root for structural checks. Browser, keyboard, and responsive checks must also cover the actual integrated app.
